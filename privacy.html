Overview

Hermes Agent is a private personal assistant operated by its owner. It accesses Google user data only after the user authorizes access through Google's OAuth consent flow.

Google User Data Accessed

Depending on the scopes authorized by the user, Hermes Agent may access:

  • Gmail messages, metadata, labels, and user-requested send or modify actions.
  • Google Calendar events and calendars.
  • Google Drive files and metadata.
  • Google Docs content.
  • Google Sheets content.
  • Google Contacts read-only data.

How Data Is Used

Google user data is used only for user-directed personal assistant workflows, including:

  • Email search, triage, status monitoring, and user-approved sending.
  • Calendar briefings, scheduling, deadline tracking, and task synchronization.
  • Locating, reading, creating, or updating Drive, Docs, and Sheets files at the user's request.
  • Looking up contact information when needed for user-requested communication tasks.

Storage

OAuth tokens are stored locally on the user's private server. Task outputs may be stored in the user's local private notes, logs, or wiki. Raw Google user data is not published.

Sharing

Google user data is not sold, shared for advertising, or transferred to third parties except as necessary to operate the user's private assistant infrastructure at the user's direction.

AI Model Training

Google user data is not used to train public AI models.

Data Deletion and Revocation

The user can revoke OAuth access at any time from their Google Account permissions page. Local OAuth tokens and locally stored task outputs can be deleted from the user's server.

Limited Use

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, contact the app owner through the developer contact email listed in the Google OAuth consent screen.
